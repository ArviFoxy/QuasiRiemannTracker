# G_outer_reference: statement map of 83 FourthPower files

**Scope.** The 83 files in `research/combined/fourthpower_map/lists/G_outer_reference.txt`: OuterFresh (29), Reference (34), RecenteredRoot (11), Restored (5), Restoration (4); 687 declaration headers in total. Source directory: `scratchpad/pr74/submissions/sil-fourth-power-20261025/src/Candidate/FourthPower/`. Read-only; no Lean edits, no `lake` or `lean` runs.

**Method.** Roles come from module docstrings. Statements are the conclusions (last lines before `:=`) of the main declarations, and a few are read in full. Full reads: `OuterFreshSelection`, `OuterFreshMixedCapacity`, `OuterFreshRootAdmission`, and the key parts of `RestoredRootSource` and `RestoredInitialSource`. Outside the list, read for context only: `GlobalSlotSelection.lean` (same directory), `MixedSupplierFourthRow.lean` (types `Frozen`/`Selected`), and `SourceFace`/`globalFace` in `submissions/hailey-collet-1252270103/` (`Record1252270103Source/Core/Contract.lean`, `Record12518109Source/InitialMoment.lean`). Declarations marked "(name)" were not read beyond their name and docstring. Arithmetic identities were checked with exact rationals. Interpretive claims are marked "(inferred)".

**Naming note.** The brief's "slope L" does not occur in any of the 83 files. The generic slope parameter is `κ` (`frozen_root_capacity`, `actual_common_capacity`). `L` is the live index finset in `OuterFreshSelection` (`liveWidth L w`).

## 2. Overview: how the four layers connect

**Outer fresh layer (OuterFresh\*).** The second Poisson stage starts from an original `Source s` and a live slot set `L`. `chosenSlots` (from `GlobalSlotSelection`, outside the list) picks a subset `J ⊆ L` with selected width `d = logb vol(J)`. The fraction is φ = 43/100 when the live width exceeds the floor ρ, and `J = ∅` otherwise. The unselected residual width is `S = liveWidth − d`. The gates are `(3/4)S < d` and `ρ/400 < d − (3/4)S`. The residual source keeps the ordinary prefix and the unselected slots. Its root capacity comes from the original root inequality with multiplier 93/25 (`residual_root_capacity`). `OuterFreshMixedCapacity` then applies genuine common allocations. `allocated_volume_log` is an exact identity, and each common loss costs `card·log 2`.

**Declared radius and admission.** `declaredWidth` (R_decl) is the formula-defined allowance. It contains `−2·logb vol(J)` and a uniform reserve `+3θ`, where θ comes from `choose_uniform_reserve` and pays the enclosure and cutoff losses. `actual_first_large_admission` proves two things. First, the physical width is at most R_decl. Second, for every second allocation, `logb(live) + 2·Σ_live w + 4d ≤ R_decl − ρ_mixed`, with the (3/4) and ρ/400 gates.

**Reference layer (Reference\*).** These are the baseline energy inputs, of the form `C(1+Height)^{2n}Z^{R+ε}·(3+T^{1/3})…`. They are proved for finite products, reflections, restrictions and punctures. Several are uniform: controls and constants are fixed before the profile. The outer and recentered layers call them as the "kept reference". `ReferenceExtractionGeometry` and `ReferenceUniformRestricted` carry the same cost shape `P+2s+4d < R`.

**Recentered root layer (RecenteredRoot\*).** `RecenteredRootSource.recenter` changes only Y₁, Y₂ and L. The total T, profiles and enclosure are unchanged. `centeredRoot_capacity` keeps the 93/25 capacity with `markedWidth`. The high-volume dispatch pays short originals by the kept reference and recenters long ones.

**Restored/restoration layer (Restored\*, Restoration\*).** `RestorationFamily`, `RestorationComplete` and `RestorationInverseEnergy` restore the full natural-slot product from restricted (injective or collision) families. `RestoredRootSource.fromFace` builds the literal root Source from `globalFace(99999/100000)(93/25)(3/50)`. Here 3/50 caps each slot weight and the total. `face_root_gates` yields the root inequality with budget `inputWidth − 1/100000`. `RestoredInitialSource.uniform_source_of_restricted` turns a restricted estimate into the full source. `global_source_of_restricted` gives `GlobalSource` on that face. The single analytic premise left in this layer is `UniformRestrictedUnitSource`.

**Connection.** The restored root supplies the global face and the root capacity. The outer stage uses the same 93/25 root multiplier and the 43/100 selection. The admission then produces the declared radius, and the outer block bounds call the reference layer.
