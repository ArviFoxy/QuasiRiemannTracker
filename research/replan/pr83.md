### 2.2 The ledger inequality = the per-step descent law

For a root with live width `w = S - f`, selected width `u in [sel w, sel w + mesh]`, retained width `s <= w - u`, packed
envelope `H = 1 + t - 6u` (CF (6.1), `SideGeometry.H`, `StepData.lean:84`; the `6u` is the cost of the selected width) and ordinary
width `P_C` (root face `P_C + (cg-f) + L*S <= B + tl`), the leaf price must satisfy (`LedgerAt`, `StepData.lean:88-92`)

    Hmin <= H <= Hmax   and   price(w0, P_C, s, H) <= u + eps/16        for every live w >= floor.

A *price* is `Price` (`CubeFree/Price.lean:29`): nonnegative, monotone, Lipschitz in (P, s, M).
* **native** (`Price.lean:176`): `price = (3/4) * deletionNeed B0 L0 c0 P s M`, with
  `deletionNeed = clip_{[0,s]} max(s - c0*M, (P + L0*s - B0*M)/L0)` (`Price.lean:41`): delete just enough *whole slots* to enter the
  parent face (kappa = 3/4 = 2*(7/8) - 1 per unit width, `NativeBootstrap.lean:25`).
* **density** (`Density/Price.lean:123`): `price = max( q(w)*deletionNeed , sup_{nu in [q(w), 3/4]} (nu*(P+s) - 10nu/(15-6nu)*M) )`,
  `q(w) = clip_{[13/20,3/4]} dens(..,(w-s0)_+)` (`Price.lean:26`).

**Native gates** `NativeGates p n a` (`Source/NativeBootstrap.lean:30-44`, kappa = nativeK = 3/4):

    retention : 0 < a - kappa*(L0 - L + (6*B0 - L0)*a)/L0            (<=> L0 - L < a*(7L0/3 - 6B0))
    overshoot : 0 < 1 - kappa*(6*B0 - L0)/L0                          (<=> L0 > 18*B0/7  — the "native barrier")
    cap       : 0 < c0*(1 - 6*a*c) - (1-a)*c
    principal : 0 < L - 2 - (9/2)*a      diagonal : 0 < L - 1 - 4a      secondRef : 0 < (3/2)L - 5/2 - (9/2)a
    refPos    : 0 < 1/6 - (1 + (3/2)a)*c      H : 0 < 1 - 6*a*c
    B <= B0 < 1,  c0 < 1/6,  0 < c,  0 < a,  L < L0
Selection is linear, `sel w = min(a,1)*w`, `s0 = 0` (every row is "new"). The recurrence of the geometric phase uses
`a = 3/25` and contracts `L - L*` by 43/50 per step (half of the retention slack at L0 ~ 2.7). The fixed point
`L* = 18*Bg/7 = 2.57117` is the native barrier; after 22 steps `L = 2.57656`, which is rounded to the face `2.58`.
(Verified exactly with rationals: all 26 steps satisfy every gate. Tightest analytic gates: `cap` early (2.6e-3) and `retention` late (2.6e-4 at step 26; 7.4e-4 at step 4);
`B_lt` is 1e-5 at step 1 and 1e-4 afterwards.)

**Density gates** `HybridGates B0 L0 c0 B L c A D` (`Source/HybridGates.lean:114-138`) with
`s0 = (B0-B)/(L0-L)` (crossing), excess `v in [0, c-s0]`, `w = s0+v`:

    u(v) = A*v/(1 + D*v),            q(v) = (999/1000)*L0*A / ((L0-L)(1+D*v) + (6*B0-L0)*A),     H = 1 - 6u,
    rho(nu) = 1 - 10nu/(15-6nu),     J(w,nu) = 1 - rho(nu) - nu*B + nu(L-1)w - (6(1-rho(nu)) - nu - 1)*u
    LOW identity (C):   L0*u - q*((L0-L)*v + (6B0-L0)*u) = (1/1000)*L0*u
    uniformly positive on [0, c-s0]:  q - 1/2,  3/4 - q,  q - 13/20,  H - 9/10,  c0*H - (w-u),  w - u,
        (1/1000)L0*A/(1+Dv),  J(w,q(v)),  (25/24)H - (B-(L-1)w-u),
        principal 1-B+(L-2)w-(9/2)u,  secondRef 1/20+(3/2)(1-B)+(3L/2-5/2)w-(9/2)u,
        second_diag 1-B+(L-1)w-4u,  ref_upper 1/3-2w-3u,  du/dv > 0.
`dsGates` (`Density/StepGates.lean:310`) turns `HybridGates` + `DSFace` into `StepGates (dsData ...)`; the ledger is `ds_ledger`
(:167): LOW part by `ds_low_aux` (:134, uses (C)), HIGH part by `ds_high_aux` (:152, uses the uniform reserve of `J` on
`nu in [q, 3/4]`, `HybridGates.high_reserve`). Upward greedy overshoot is harmless because `q*(6B0-L0) <= L0`
(`dsDens_overshoot`, :89) — so **the native barrier 18B/7 disappears in the density regime**; instead the floor
`q >= 13/20` (a hard-coded clip, `densQ`, `Density/Price.lean:26`; the HIGH bins live in `[33/40, 7/8]`, `LeafHigh.lean` header) and the HIGH
reserve `J > 0` take over.

### 2.3 Mathematical content (as read from the Lean docstrings; the design papers are not shipped)

* **Source / row objects.** Hecke (sextic) characters over the Eisenstein integers `O = Z[omega]`
  (`ActualEisensteinCubic.O`), columns = ideals/elements of `O` (the baseline OAI framework). A source bounds a weighted
  second moment of "rows" built from two ordinary profiles (lengths `X1, X2`) and prime slots of widths `w_i`
  (prime pools of norm ~ `Z^{w_i}`), see `PricedPackedAt` (`CubeFree/Leaf/Contract.lean:38`).
* **Cube-free columns, K3 local kernels.** Columns have `v_P <= 2` at every prime (`ElementCubeFree`,
  `CubeFree/FifthFreeBridge.lean:18`; cube-free => fifth-free, so FP's `GaussTransfer.normalized_fourth_power` is reusable,
  `cubeFree_fifthFree` :36). The restricted local factor of the ordinary pair is
  `H3 = B*T3`, `B=(1-x)(1-y)`, `T3 = sum_{i+j<3} x^i y^j` (`CubeFree/LocalKernels.lean:19-30`; PR 76 had `T5`, `LocalKernels.lean:11-14`
  there, `Fin 12` / `Fin 14` tables replaced by `Fin 8` / `Fin 10` in `FP/KernelCoefficients.lean`). The square-zero marked kernels
  `K3 = H3 + z(B - H3)`, `K3^-1 = H3^-1 + z(H3 - B)H3^-2` satisfy `K3*(F+zF) = T3 + z` and `K3^-1*(T3+z) = F+zF`
  (`forward_cube` :33, `inverse_cube` :39, instances of PR 76's `forward_operator`/`inverse_operator`). At central exponent
  1/2 and `N(P) >= 4`: `|H3 - 1| <= 4r^3 + 3r^4 < 1` (:48, :75).
* **Consequence for masses** (`CubeFree/KernelForwardMass3.lean:1-14`, `ordinary_mass_enclosed` :76): with weights `x -> N(P)^{-2/3}`,
  `y -> N(P)^{-1/3}` every nonconstant monomial has prime exponent `(2i+j)/3 >= 1`, equality at `y^3`. Local mass
  `<= 1 + 7/N(P)`, so FP's *constant* global mass bound (exponent 5/3 > 1) has no analogue; it is replaced by
  `prod_{N(P) <= X} <= e^{42 log 768} (log X)^42 <= C X^delta` (`Analysis/PrimeHarmonic.lean`: Mertens-type
  `sum 1/N(P) <= 6 log log X + 6 log 768`). Every downstream mass statement must carry the enclosure `N(P) <= X`.
* **Artificial divisors.** FP paid the first artificial-divisor sum `sum_u mu(u) matrix_u` divisor by divisor (kernel Cauchy per `u`
  with budget `E/N(u)`, then harmonic mass). Here `sum_u` stays *inside* the Hilbert-space Cauchy inequality:
  one `whole_kernel_row_estimate` on the joint row type `Id x O` with row phase `mu(u)*commonPhase(1,z)`
  (`First/JointKernel.lean:1-20`, `summed_kernel_from_raw` :223); no artificial-divisor mass is paid
  (`First/RawSidesBlock.lean`, `RawSidesRetained.lean`). The regrouping identity is `first_divisor_regroup`
  (`Second/FirstDivisor.lean:154`): `sum_u 1_{u|n1} 1_{u|n2} = 2^{omega(gcd)}` (CF (4.2)). A forced deviation from the design
  ("STOP-RULE REPORT", `Second/Concrete.lean:1-30`): for first common pairs with `c > d` (e.g. multiplicities (2,1)) each raw side
  exceeds the per-side FP budget by `Z^{(c-d)-allow}`, but only the *product* of the two sides matches CF (3.1)/(6.4), so the contract is
  the **balanced** `BalancedSummedRawSideBounds` (`Concrete.lean:184`, `balanced_kernel` :202).
* **Selection and D^4 transfer.** A block `D` of whole slots of total width `u = sel(w) (+ mesh)` is selected from the slot widths alone
  (`Second/Selection.lean`, adapted from PR 76 `GlobalSlotSelection`/`OuterFreshSelection`, target `43/100*w` replaced by arbitrary `sel`),
  then the D-Cauchy and the `D^4` transfer `k -> D^4 k` at `f = 1` (`Second/FourthTransfer.lean:35`, `selected_row_fourth_one`; Gauss radius
  `K -> K N(D)^4`, i.e. `16 K W^4`). This is Sil's fourth-power lane, now with cube-free columns.
* **Second common divisors, grouped at the physical row.** Second-step labels (genuine common ideal `G = C2/D2`, second artificial
  divisor `t2`, twist `A2`) are grouped by their coefficient class at the packed row `y = V0*A2*z` with a bounded divisor fibre
  (`Packet/Grouped*.lean`, `Packet/Fibre.lean`: `tau(r)^k <= C Z^delta`), and a *common-profile separation*
  (`Analysis/CommonProfile.lean`, `weighted_separation` :92; `Packet/ProfileSeparation.lean`, `prefix_hrep` :661, `prefix_weighted_separation` :810):

  profile (`Packet/GroupedClass.lean`, `class_bound` :36). `Packet/Grouped.lean:37 grouped_side_bound_of_leaf` is "Seam B".
* **Growing twists packed into the row, finite anchor dictionary.** `Packet/Dictionary.lean`: anchors `rayAnchor eta j`, `j` in `RayCharacter`

### 2.4 Columns divisible by p^2 and collisions

Three different things, which should not be conflated:

1. **p^2 inside a column (cube-free).** Allowed (`v_P <= 2`; `T3` contains `x^2, xy, y^2`); `p^3` and beyond are excluded from the restricted
   family and recovered by the K3 kernel (mass `<= 1+7/N(P)`, subpower Euler product). Common-divisor consequences:
   `idealCorrelation_cubefree_unequal_zero` (`Second/FirstDivisor.lean:208`): multiplicities (1,2) at a common prime kill the second Gauss
   correlation identically (`actual_unequal_min_six`: min multiplicity not divisible by 6); `cubefree_equal_of_ne_zero` (:222): a nonzero
   second correlation has equal multiplicities at every common prime; `norm_le_rad_sq` (`ConcreteCaps.lean:35`) `N(G) <= N(rad G)^2`;
   `dvd_rad_sq` (`ProviderLabelData.lean:43`); labels with a given column number at most `tau(G^2)^2 2^{omega(G)} <= tau(G^2)^3 <= C Z^delta`
   (`ConcreteLabelAssembly11.lean:98 mult_subpower`); `Packet/FirstSidePacking.lean` (multiplicities in {1,2} give
   `N(V_C) N(D-common) = N(e) N(r) N(C-common)`, i.e. `q_C = q + c - d`, and `span V_C | (C-common)^2`).
2. **A prime appearing in two *marked slots* (repeated marks / collisions).** Inherited unchanged from PR 76 (our PR): restricted rows are
   `(T, w, r, A)` with `r` the collision setoid on the slot set and `A` the inverse-deleted singletons (`Assembly/Rows.lean:238-290`
   `rowWidth`, `RestrictedRowAt`); genuine repeated blocks keep their original half-powers
   (`CubeFree/FP/RestorationCollisionEnergy.lean`, `RestorationInverseEnergy.lean`, `RestorationComplete.lean`, 117 of the 219 FP files are
   "mechanical cube-free forks, mathematics unchanged"). The row's *marked width* is only the remaining singletons; rows narrower than `s0`
   go to the parent.
3. **Common primes between the two sides (first step).** Unequal multiplicities (2,1) are possible and cost `Z^d`
   in a per-side budget; the balanced contract above absorbs it.
