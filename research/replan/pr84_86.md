## 0. Bottom line

1. **[M] Three different kinds of increment.**
   PR 84 = PR 83 tree + ONE more big density step (ΔL=0.06). PR 85 = PR 84 tree + TWO big sibling steps from the same parent (a "physical" child and a "count" child, ΔL=0.0133 and 0.033) + a 4-branch return.
   PR 86 = *dependency* on PR 83 (imports 489 of its 537 modules) + 46 tiny density steps (ΔL=0.005 each) + a copy of Sil's return with new constants. PR 86 does not use PR 84/85 at all (`metadata.json` `dependencies`).
2. **[M] Why PR 86 jumped (-2.5e-5 vs PR 85) and PR 84/85 did not (-1e-5, -4e-6).** The source chain is a discretisation of a one-dimensional flow B(L). PR 83/84/85 end on faces that sit 1.7e-3 .. 1.9e-3 *below* the continuum
   flow (big steps lose B at every step); PR 86's face is only 7.8e-5 below it. Using the return's sensitivity (-0.0132 per unit B), that is ~2.5e-5 of theta recovered. The return itself was *not* improved structurally in PR 86 (Sil's boxes, windows and formulas are unchanged; only constants + regenerated coefficients + one row split).
3. **[M] The chain is already stopped at its economic optimum.** Per-step gain in theta falls from 2.2e-6 (step 1) to 0.4e-6 (step 46). The return values 1 unit of B at ~14 units of L (d theta/dB = -0.0132, d theta/dL = +0.00093), so a step only pays while its crossing slope s0=ΔB/ΔL stays below the break-even slope: 0.0705 for one shared final face (0.086 if only the *count* face is considered, 0.060 for the *physical* face). PR 86's last slope is 0.0651, the next greedy step would need 0.085, the one after is infeasible (density-floor wall q>=13/20, L/B ≈ 2.365).
4. **[X] Headroom of this line under the current analytic constants: ≈ -2.3e-6 (best ≈ 0.8739535)**, composed of finer chain (-1.0e-6 in the continuum), role-split faces (-0.8e-6 .. -1.1e-6) and exact c (-0.25e-6). Cheapest piece: the *role split* (count face = chain end, physical-edge face = chain step ≈38) ≈ -8e-7 with no new step files. **The one structural wall is the density floor q>=13/20** (= zero-density range a>=33/40 of Collet's Lemma 2.1): the count role would keep paying until s0≈0.085 (L≈2.20, q∞≈0.60); lowering the floor to ≈0.60 (a>=4/5) is worth another **≈ -8.7e-6** (best ≈ 0.8739447) *if* the 33/40 in `Cycle61/Density/*` is a proof artefact (unknown). 5. **[M] The return is tight to 2.5e-7**: the submitted c (0.1260442) is within 2.5e-7 of the model optimum 0.12604445 for the PR 86 face; the certificate slack is 7e-8 in rows row023a/b (`[86]Return/Rows/Edge_newTop_2.lean`), 1.4e-7 in row024, 8.8e-7 in row021.

## 2. The chain-step mechanism in PR 86 `Source/`

### 2.1 What one density step must satisfy (generic, `[83]Source/HybridGates.lean`)

Step from parent G(B0,L0,c0) to child G(B,L,c) with parameters A, D. Put s0=(B0-B)/(L0-L) (`cross`, :32), v in [0, c-s0], w=s0+v, u(v)=A v/(1+D v) (`sel`, :38), H=1-6u, rho(nu)=1-10nu/(15-6nu) (:55),
q(v) = (999/1000)·L0·A / ((L0-L)(1+D v) + (6B0-L0)A) (`dens`, :48-49), J(w,nu) = 1-rho(nu)-nu B+nu(L-1)w-[6(1-rho(nu))-nu-1]u (`highJ`, :62-63).
`structure HybridGates` (:114-138) requires, **uniformly on all of [0, c-s0] with a positive reserve**:
`q>1/2`, `q<3/4`, `q>=13/20` (density floor, :74), `H>9/10`, retained cap `c0 H-(w-u)>0`, retained width `w-u>0`, `J(w,q(v))>0` (high_at_q), `25/24 H-(B-(L-1)w-u)>0`,
principal `1-B+(L-2)w-9/2u>0`, second-ref `1/20+3/2(1-B)+(3L/2-5/2)w-9/2u>0`, second-diag `1-B+(L-1)w-4u>0`, ref-upper `1/3-2w-3u>0`, plus the trivial `low-per-width>0` and `du/dv>0`, and the LOW identity (C) as an algebraic identity.

### 2.4 Is it a discretisation of a flow? Yes - and the limit is closed-form

**[M] The binding gate is J(w,q(v)) at v≈0.** At v=0 (u=0, w=s0) J = q[10/(15-6q) - B + (L-1)s0]; using B = B0 - s0ΔL, L = L0-ΔL this is exactly
`J(0) = 0  <=>  s0 = (B0 - 10/(15 - 6 q0)) / (L0 - 1)`, `q0 = 0.999 L0 A / (ΔL + (6B0-L0)A)`.
As ΔL -> 0, q0 -> q_inf = 0.999 L0/(6B0-L0) (independent of A, D) and the chain becomes the ODE

&nbsp;&nbsp;&nbsp;&nbsp;**dB/dL = ( B - 10/(15 - 6 q) ) / (L - 1),  q = 0.999 L / (6B - L),  B(2.5715) = 0.99999.**

Walls: q<=3/4 at the start (L/B ≈ 2.5729, essentially the native barrier 18/7 = 2.5714, which is why native steps hand over to density steps at L=2.5715), q>=13/20 at the end (L/B = 3.9/1.649 = 2.3651; ODE reaches it at **L=2.33831, B=0.988685**).
